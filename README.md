# Todo Task Manager

シンプルなTodoタスク管理アプリです。ビルド不要、依存関係なしのVanilla HTML/CSS/JavaScriptで構築されています。

## 機能

- タスクの追加・削除・完了チェック
- 優先度（低・中・高）の設定
- 期限日の設定と期限切れの表示
- フィルター（すべて・未完了・完了済み）
- 完了済みタスクの一括削除
- カレンダー表示（Googleカレンダー風の月表示、期限日ベースでタスクを表示・日付クリックで追加）
- ブラウザの localStorage によるデータ永続化

## 使い方

`index.html` をブラウザで直接開くか、簡易サーバーを起動してください。

```bash
python3 -m http.server 8000
```

その後 `http://localhost:8000` にアクセスします。
